# Media provenance

Prepared 27 October 2026 for a portfolio case study. All restaurant records shown are synthetic. No original client photographs, logos, catalog assets or operational records were used in the published media.

These are labeled English localization previews. Playwright captured the existing application's rendered components after browser-only translation, left-to-right formatting, illustrative USD display and replacement of synthetic test phone strings with reserved US example numbers. The native app is not pictured. No screen was generated by an image model. The source implementation remains Arabic-first and requires market adaptation; see [verification](../VERIFICATION.md).

The synthetic menu is an original casual-grill example. Ember & Oak Grill and its simple E&O text monogram are fictional content prepared for these previews. Customer names such as Demo Guest, the manager label, addresses, orders and cash values were created for the demo. No QR codes are displayed. No live URL or browser address bar appears.

## Food imagery

Five original menu photographs were generated with OpenAI's built-in image-generation tool: a smash burger, grilled chicken sandwich, BBQ wings, loaded fries and garden salad. They appear only as image assets inside the captured preview screens. Drink items use the application's existing icon fallback. No third-party restaurant photos were reused. Generated food photography is illustrative, not a claim about an actual dish or serving.

## Promotional cover

`showcase/cover.webp` is generated promotional artwork using `01-customer-menu.png` and `04-staff-order-queue.png` as authoritative visual references. The cover adds frames, background shapes and typography. It is an illustrative composition, not a further screenshot or feature test. Refer to the individual previews for interface details; small text in generated compositions may differ from the captures.

Only one cover was selected. Additional generated candidates and an unused food-scene image are excluded. Full prompts for the selected cover and five food images are retained in [PROMPTS.md](PROMPTS.md). Generated masters and private preparation scripts are not distributed.

## Export and review

Final screenshots are optimized PNGs. The cover is an optimized WebP export. Re-encoding removed unnecessary embedded metadata without adding private information. Pixel dimensions and file hashes are recorded in the publication inventory. Review included visual inspection, untranslated-text checks, synthetic-data checks, QR decoding, local image-link rendering and metadata inspection.

Rendered typefaces and icons originate from the application's licensed self-hosted fonts and Lucide icon library. Applicable notices are preserved in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). No font files, application source or icon library code are distributed. See [rights](../RIGHTS.md).
